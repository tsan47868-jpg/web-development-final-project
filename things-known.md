## Deploy and Publish SpendWise Using GitHub & Netlify

# <i>Description</i>

Congratulations on completing the Web Hosting and Deployment module.

For this assignment, you will take your SpendWise project from a local application to a live website accessible on the internet.

You are required to deploy your project using <b>GitHub</b> and <b>Netlify</b>, test it thoroughly, and verify that automatic deployments are working correctly.

Your complete SpendWise project files.
A properly completed README.md.

Publish SpendWise to the Internet

Throughout this week, you learned how modern websites are deployed using GitHub and Netlify.

Your task is to publish your SpendWise project and make it accessible online.

Requirements
Part 1: Deployment Readiness

Review your project structure and ensure all files are organized correctly for deployment.

Part 2: GitHub Repository

Create a public GitHub repository and upload your SpendWise project.

Part 3: Netlify Deployment

Connect your GitHub repository to Netlify and deploy the website.

Part 4: Custom Site Name

Update the default Netlify subdomain to a more meaningful name related to your project.

Part 5: Continuous Deployment Test

Make a visible change to your application, push the changes to GitHub, and verify that Netlify automatically updates the live website.

Part 6: Final Testing

Test the deployed website and confirm that all pages, styles, scripts, and assets load correctly.
