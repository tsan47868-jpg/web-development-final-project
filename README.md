# SpendWise

SpendWise is a responsive personal budget dashboard. Enter a monthly budget, expenses, and a savings goal to see your spending totals, category breakdown, and progress update.

## Technologies

- HTML
- CSS
- JavaScript
- Browser local storage for data saved on the current device

## Run locally

Open `index.html` in a modern browser. Add your own budget, expenses, and savings information. The dashboard starts empty; information you enter is saved in that browser on that device and is not sent to a server.

## Deployment process

1. Push `index.html`, `style.css`, `script.js`, and this README to the public GitHub repository.
2. In Netlify, create a new site by importing that repository. This is a static site, so no build command is needed; publish the repository root.
3. Set a memorable Netlify site name and wait for the first deployment to finish.
4. Open the published URL and test adding a budget, expense, and savings goal. Check that the page reload retains the entered data.
5. Make a small visible change, push it to the connected GitHub branch, and verify that Netlify publishes a new deployment.
6. Test the final published site and add its URL to the section above.
